# Sprint 4 – Building Business Logic with Apex

This repository contains the work completed for Sprint 4 of the Salesforce Developer Bridge Program.

## Topics Covered

* Business Logic
* Business Rules
* Apex Classes
* Service Class Design
* ApplicationService
* Software Architecture Basics
* Method Design and Parameters

## Learning Outcomes

* Understood the importance of business logic in enterprise applications.
* Learned how software makes business decisions using rules.
* Identified business responsibilities and mapped them to Apex service classes.
* Designed the ApplicationService class for handling job applications.
* Explored how methods, parameters, and return values support business processes.

## Project Scenario

The Placement Management System requires business logic to:

* Prevent duplicate applications.
* Validate student eligibility.
* Check application deadlines.
* Process job applications correctly.
* Provide meaningful feedback to users.
