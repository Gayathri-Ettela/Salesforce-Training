# Salesforce Developer Bridge Program – Day 5

This repository contains the Day 5 Apex Development tasks completed as part of the Salesforce Developer Bridge Program.

## Topics Covered

* SOQL Queries
* DML Operations
* Apex Classes
* Business Logic Implementation
* Student Eligibility Validation
* Duplicate Application Prevention
* Application Status Management

## Tasks Completed

* Retrieved student information using SOQL.
* Retrieved job eligibility criteria.
* Prevented duplicate job applications.
* Created and saved application records.
* Updated application status based on recruiter decisions.
* Implemented a complete placement application workflow.

## Key Learnings

* Using SOQL to retrieve Salesforce records.
* Using DML to insert and update records.
* Implementing business rules in Apex.
* Building service-based application logic.
* Developing end-to-end business transactions.

## Project

**Placement Management System**

The project automates the student placement application process by validating eligibility, preventing duplicate applications, managing application records, and tracking recruitment status.
